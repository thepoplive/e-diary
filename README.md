# Электронный дневник (college diary)

Веб-приложение электронного школьного/колледжевского дневника с ролями: **главный администратор, учитель, ученик, родитель**. Русский интерфейс, аккуратный серверный рендеринг без фронтенд-фреймворков.

## Возможности

### Главный администратор
- Дашборд со сводной статистикой (ученики, учителя, оценки, замечания)
- База данных: создание/редактирование пользователей (все роли), группы, генерация логинов/паролей
- Расписание уроков на неделю для каждой группы (поурочная сетка, кабинеты, учителя)
- Расписание звонков (изменяется в любой момент)
- Каникулы (учёт «не учебных» дней)
- Рассылка уведомлений с закреплением (до 3 закреплённых сообщений на пользователя)
- Заявки на изменение оценок: подтверждение/отклонение
- Настройки сроков редактирования оценок

### Учитель
- Уроки на сегодня: посещаемость + оценки + комментарии в одной форме
- Расписание на неделю (включая «все группы», если включён доступ)
- Расписание звонков
- «Мои ученики» и «Родители» (привязка через группу)
- Изменение оценок с возрастными правилами:
  - в пределах срока — без подтверждения;
  - после срока — заявка администратору с обязательным комментарием;
  - после полного срока — изменение недоступно

### Ученик / Родитель
- Главная, уроки на сегодня, неделя, звонки
- Оценки и посещаемость с комментариями/причинами (замечания, прогулы)
- Замечание на занятии = оценка «!»

## Технологии
- **Backend:** FastAPI, SQLAlchemy 2, JWT (httpOnly cookie), PBKDF2 (без сторонних либ для паролей)
- **БД:** PostgreSQL (через переменную окружения), автоматический фолбэк на SQLite
- **Frontend:** Jinja2-шаблоны, чистые CSS/JS
- **Время:** отображение в МСК (UTC+3)

## Запуск

```bash
# 1. Установить зависимости (Python 3.10+)
pip install -r requirements.txt

# 2. (Опционально) настроить PostgreSQL. Пример .env:
#    DATABASE_URL=postgresql://user:password@localhost:5432/diary
cp .env.example .env

# 3. Запустить
python -m uvicorn app.main:app --port 8077
```

При первом старте автоматически создаётся главный администратор. Логин `admin`, пароль печатается в консоль/логи (`server_err.log`).

Учителей, учеников и родителей создаёт администратор через раздел «База данных».

## Тесты

Интеграционные тесты требуют запущенный сервер:

```bash
python -m uvicorn app.main:app --port 8077
python test_e2e.py        # основной флоу: вход, пользователи, уведомления, порталы
python test_grading.py    # оценки/посещаемость, заявки на изменение, лимит закреплений
python test_permissions.py# разграничение ролей
```

## Структура

```
app/
  main.py          # startup, админ, обработчики ошибок
  models.py        # ORM-модели
  auth.py          # хэширование, JWT, роли
  routers/         # auth, admin, teacher, parent, student
  templates/       # Jinja2 (отдельные папки по ролям)
  static/          # style.css, app.js
test_*.py          # интеграционные тесты (со стартовым паролем определяются автоматически)
```
